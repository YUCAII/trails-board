## English

One APK with Chinese, English and Japanese switching. The selected language is remembered. Translations cover quests, walkthrough steps, notebook text, recommended choices and achievement requirements.

- 87 quests, 113 choice groups, 178 in-game achievements and 43 Steam achievements.
- Cross-language search, local completion tracking and chapter/type filters.
- Phone layouts support longer text; switching language preserves progress.
- Android 6.0+. Package `com.trails.board.multilang` can coexist with v9; v9 progress does not migrate automatically.

Download **trails_board_v10_multilang.apk** below. Checksums are in `SHA256SUMS.txt`. Translation and DOM integration checks, phone-width layout checks and official Android v1/v2 signature verification passed. Physical Android installation has not yet been tested.
